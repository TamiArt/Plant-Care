# Источники и пополнение каталога PlantCare

## Почему используется два слоя данных

Единого бесплатного открытого источника, который одновременно содержит научную
таксономию, садовые сорта, русские названия и проверенные инструкции по уходу,
у проекта нет. Поэтому каталог устроен без платных API и обязательных ключей:

1. **Локальные редакционные карточки PlantCare** поставляются вместе с приложением,
   работают офлайн и содержат практические рекомендации по уходу.
2. **GBIF Public API** используется только при наличии интернета как дополнительный
   поиск по мировой научной таксономии. Результат GBIF не превращается автоматически
   в рекомендацию по уходу.

Такой подход не зависит от тарифа внешнего сервиса. При недоступности GBIF поиск по
локальным карточкам, сад пользователя, история ухода и резервные копии продолжают
работать.

## Что добавлено в локальный слой

Дополнительная подборка находится в `src/features/catalog/additionalData.ts` и
включает востребованные названия, которые часто отсутствуют в научной выдаче:

- калатеи (включая «Вайт Фьюжн», «Медальон», «Бьюти Стар» и другие);
- спатифиллумы («Пикассо», «Домино», «Сенсейшн», «Шопен»);
- садовые розы разных групп и сортов;
- популярные хосты, пионы, туи, рододендроны и гортензии;
- клематисы, астильбы, гейхеры, лилейники и лаванда;
- популярные марантовые, филодендроны, алоказии, бегонии и традесканции.

Для новых сортовых карточек намеренно не подставляются случайные фотографии из
поиска: до появления проверенного изображения интерфейс показывает нейтральный
эмодзи. Это исключает ситуацию, когда название сорта и фотография не совпадают.

## Правила дальнейшего пополнения

Для каждой новой карточки необходимо:

1. задать уникальный стабильный `id`;
2. проверить принятое ботаническое или сортовое написание;
3. добавить русское название и точные поисковые теги;
4. сформулировать осторожные рекомендации с учётом сезона и условий содержания;
5. не использовать изображение без подтверждённых прав и соответствия растению;
6. добавить карточку в автоматические проверки целостности каталога.

Пользовательские данные в этот набор не отправляются. Локальный каталог является
частью статической сборки Vercel и кэшируется PWA для офлайн-работы.
