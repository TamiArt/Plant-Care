# Бесплатный ИИ-помощник PlantCare

## Как он работает на Vercel

Помощник не требует API-ключа, аккаунта, банковской карты или платного backend. Каждый пользователь получает ответ по следующей цепочке:

1. Если браузер предоставляет встроенную language model, вопрос обрабатывается локально этой моделью.
2. При локальной разработке на `localhost` можно использовать установленный пользователем Ollama; запрос ограничен таймаутом 4 секунды.
3. Во всех остальных случаях, включая обычный сайт на Vercel, отвечает встроенный офлайн-эксперт PlantCare.

Третий уровень входит прямо в JavaScript-сборку и поэтому доступен всем пользователям после загрузки приложения. Он распознаёт распространённые темы: полив, свет, пожелтение, пересадка, подкормка, вредители, размножение, симптомы, влажность и безопасность.

## Приватность

- Офлайн-эксперт не отправляет вопрос, фотографии, заметки или историю растения на сервер.
- На Vercel приложение не обращается к `localhost` пользователя.
- Ollama используется только при открытии приложения с `localhost`.
- Встроенная browser-модель вызывается только если сам браузер сообщает о её наличии.
- Платные облачные AI API отсутствуют.

## Ограничения

Встроенный эксперт использует проверяемые локальные правила, а не свободную генерацию. Это гарантирует доступность и предсказуемость, но он не знает ответ на любой возможный вопрос. Для неизвестного вопроса он предлагает поддерживаемые темы.

Ответы не являются диагнозом. Помощник не определяет токсичность неизвестного растения, не назначает лечение и не предлагает смешивать химические средства. В потенциально опасной ситуации он рекомендует обратиться к врачу или ветеринару.

## Нулевой fallback

Недоступность browser AI, Ollama, GBIF или интернета не блокирует чат: встроенная база знаний продолжает отвечать. Основные функции сада также не зависят от помощника.
